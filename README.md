One sharp, funny loading-screen tip for a stressed developer and the AI coding agent sitting beside them, waiting on the same build. The joke lands on the one thing the two of them do differently while the progress bar crawls: one panics, the other cannot — so the tip tells the human to copy the machine for once.

## Run it

```sh
node main.ts
```

This reads `entry.txt`, checks it is a single line of 1–200 characters, and writes it unchanged to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is not set).
